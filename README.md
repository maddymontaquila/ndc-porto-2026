# ndc-porto-2026

NDC Porto 2026 demos and slides for Maddy and Adam.

## Slides

`slides/` contains the NDC Porto 2026 "Use agents to build agents with Aspire + Microsoft Agent Framework" deck (`slides/agents/`), featuring Maddy Montaquila and Adam Ratzman.

From `slides/`, run `npm ci` and `npm run dev` to edit, or `aspire run` to launch it from the Aspire dashboard. See `slides/README.md` for details.
