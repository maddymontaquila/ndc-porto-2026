# ndc-porto-2026

NDC Porto 2026 demos and slides for Maddy and Adam.

## Slides

`slides/` contains the "Use agents to build agents with Aspire + Microsoft Agent Framework" deck (`slides/agents/`), imported from [techoramanl-2026](https://github.com/maddymontaquila/techoramanl-2026) as a starting point. It still carries Techorama branding.

From `slides/`, run `npm ci` and `npm run dev` to edit, or `aspire run` to launch it from the Aspire dashboard. See `slides/README.md` for details.
