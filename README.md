# ndc-porto-2026

NDC Porto 2026 demos and slides for Maddy and Adam.

## Slides

`slides/map/` is the NDC Porto deck, "Aspire is the map your coding agent is missing" (Maddy Montaquila and Adam Ratzman, Thu 19 Nov, 11:40, Room 2). It was designed with the Aspire Design System and ported to the repo's Reveal.js setup, so it presents offline from `npm run build` and `npm run preview`.

`slides/` also contains the "Use agents to build agents with Aspire + Microsoft Agent Framework" deck (`slides/agents/`), imported from [techoramanl-2026](https://github.com/maddymontaquila/techoramanl-2026) as a starting point. It still carries Techorama branding.

From `slides/`, run `npm ci` and `npm run dev` to edit, or `aspire run` to launch it from the Aspire dashboard. See `slides/README.md` for details.
